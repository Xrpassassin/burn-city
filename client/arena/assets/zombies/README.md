# Zombie Ash model

- Source: [Storm Apocalypse — zombie-ash.glb](https://github.com/mars-tw/storm-apocalypse/blob/main/public/models/custom/zombies/zombie-ash.glb)
- Upstream project: [mars-tw/storm-apocalypse](https://github.com/mars-tw/storm-apocalypse), MIT License; the full MIT license text is copied into this directory.
- Format: binary glTF 2.0, skinned character with animation clips `Idle`, `Walk`, `Idle_Attack`, `HitReact`, and `Death`.
- Use in BURN City is an opt-in visual experiment only. The procedural zombie renderer remains the default/fallback.
