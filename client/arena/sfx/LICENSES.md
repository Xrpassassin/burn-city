# Zombies sound effects: sources and licenses

Every file in this folder was made from recordings released under **Creative Commons 0 (CC0 1.0, public domain dedication)** on Freesound.org.
CC0 needs no attribution and allows commercial use, modification and redistribution; credits are listed anyway.
License text: https://creativecommons.org/publicdomain/zero/1.0/

Source files are the Freesound high-quality MP3 previews of each sound (same recording, same CC0 license), checked on each sound's page on 2026-10-20.
Processing (ffmpeg, tools in the commit message / HANDOFF): trimmed, mono 44.1 kHz, pitched down (asetrate) for weight, layered (e.g. roars = two pitch layers, shotgun = blast + low thump + echo tail), echo/low-pass for distance, loudness-normalised (loudnorm), faded, encoded MP3 96 kbps.
No audio was ripped from any game.
