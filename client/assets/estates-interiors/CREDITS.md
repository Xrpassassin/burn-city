# Estates walk-in home furniture

Optimized from CC BY 4.0 Sketchfab models with `scripts/estates-interior-models/build_interior_model.py` (merged into one mesh, decimated, re-scaled and re-oriented to face +Z, unused PBR maps removed, colour textures resized to at most 256 px WebP). They load only while a player is inside a home and are released on exit. Raw downloads are not committed. Sources and licence metadata: `scripts/estates-interior-models/sources.json`. Public credits: `client/city-credits.html`.

The same shipped models are reused to furnish rooms more fully as an estate's already-unlocked typoon upgrade count rises (basic / furnished / premium). Unsold and show-home tours stay on the basic set. No new meshes were added in that pass. The existing chandelier’s emissive was reduced so it reads as warm brass instead of blown-out white.
