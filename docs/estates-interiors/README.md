# Estates walk-in homes

Interiors for every Estates tier (Trailer, Apartment, Starter, Family, Mansion), sized from the exterior footprint in `estates-house-design.mjs` with the front door and windows in the same places as the outside. Screenshots come from a WebGL harness (SwiftShader); "dollhouse" shots hide the ceiling and front wall.
