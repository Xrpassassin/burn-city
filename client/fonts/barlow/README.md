# Barlow + Barlow Condensed (self-hosted)

- Family: **Barlow** (UI body: 500, 600, 700) and **Barlow Condensed** (display, headings and numbers: 600, 700, 800, 800 italic)
- Author: Jeremy Tribby / The Barlow Project Authors, https://github.com/jpt/barlow
- License: **SIL Open Font License 1.1** (see `OFL.txt` here). Free for commercial use; the fonts are bundled, not sold.
- Source: Google Fonts (latin subset woff2, v13), downloaded 2026-11-20. Unmodified apart from Google's latin subsetting.
- Both families ship the `tnum` (tabular figures) OpenType feature, used for currency and counters.
