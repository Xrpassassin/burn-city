# Kenney Modular Space Kit (subset)

Source: https://kenney.nl/assets/modular-space-kit
Creator: Kenney (www.kenney.nl)
License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/)
Acquired: 2026-11-26

Vendored GLBs are a small wall/door/floor/cable subset used as visual
cladding on The Ashen Cosmodrome. Collision, doors, windows, pads, buys
and spawns stay on the server grid. Runtime only tints materials to the
BURN ember palette (MeshBasic, unlit).
