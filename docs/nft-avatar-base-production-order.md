# NFT base-model production order

Locked sequence: **RACC → 589 Protocol → Firekeepers**.

## Definition of done for each collection
1. Collection-specific base silhouette reviewed against licensed/reference collection artwork (not a generic stand-in).
2. One cohesive, visually approved character with face, body and hands/feet in front, three-quarter, side and rear views.
3. Clean deformable topology at neck, shoulders, elbows, hips and knees; RACC also tail; Firekeepers also robe controls.
4. Weighted to a common locomotion skeleton with documented collection-specific bones.
5. Idle, walk, run, turn and interact clips checked for clipping and foot sliding.
6. GLB export/import verified in the actual game with mobile performance measurement.
7. Explicit art, rights, rig and performance approvals; no approval inferred from script success.

## Gate policy
- RACC must pass the base-model acceptance gate before active production of 589.
- 589 must pass before active production of Firekeepers.
- Do not add NFT token-specific traits during these base-model milestones.
- Retain original authored sources and reproducible export manifests.
- Current Blender procedural models and voxel-fused meshes are **blockouts**, not finished assets.
- No Blender render, skinning, or in-game validation has been confirmed as of this document.
