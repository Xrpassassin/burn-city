# Ashen Cosmodrome environment — attribution

Selected, compressed-enough low-poly props used to dress **The Ashen Cosmodrome**, BURN City's second Zombies map. They do not copy Activision, Treyarch, or Black Ops assets, names, or audio. Server collision comes from authored `obst` footprints in `server/cosmodrome-map.js`; these GLBs are visual only.
