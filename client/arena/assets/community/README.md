# Community model intake — Homefront and ORIGINAL Zombies

The BURN City game uses locally bundled, license-verified GLB assets, not Sketchfab embed scripts or temporary CDN URLs.

**Two audited and locally licensed model binaries are now bundled:** the creator's 10k-triangle humanoid `homefront-male-survivor.glb` (source FBX, 1K embedded author albedo and original authored Walk/Run/Jump on the Mixamo-style rig) and `homefront-street-props.glb` from MadeByYeshe/CrazyDrPants. Its 9,826,272 bytes, 20,667 triangles, 56 mesh nodes, 38 materials, SHA-256 `30b97656624cb6596495b7aa343f87c42c01124717cdb0975fdde0fcf7edf332`, and mesh names were independently recorded from the official free itch.io download in `street-props-acquisition.json`. Its record is `installed:true`, so the optional Homefront street-dressing adapter can render the six verified submesh families. The other **four** entries in `../../community-art-intake.mjs` remain `installed:false`. The original male survivor was converted from the artist's official [free FBX download](https://codersan.itch.io/zombie-apocalypse-survivor-male-3d), validated using original source checksum and has a separately recorded GLB checksum in `homefront-survivor-verified.json`. **No Unity Starter Assets animation clips were copied into this model**: Walk/Run/Jump were generated specifically for the game as original quaternion tracks over the existing author rig. All parts have fallback behavior, and the player silhouette is a temporary human placeholder until faithful NFT avatars are implemented. Never flip another entry or claim a model is deployed without its audited GLB, animation inspection where applicable, and SHA-256.

## File acquisition — only official channels

1. The street pack was obtained through the original creator's official free/name-your-price itch.io download, which provides a 9.3 MiB combined GLB. Its 9,826,272-byte vetted archive and `street-props-acquisition.json` are in this folder. The original file names include `Big Bin Body`, `Red Trash Can`, `Wood Bench`, `Concrete Barrier`, `Street Light`, and `Bag 1` (not the generic names in the original intake proposal). The ephemeral Cloudflare signed URL expires quickly and is **never** pasted into the game.
2. The survivor creator provides FBX on [itch.io](https://codersan.itch.io/zombie-apocalypse-survivor-male-3d); Sketchfab lists CC BY for this creator's model. Download the creator's FBX archive using official sources and inspect animation clips — the third-person Unity controller may contain separate animation dependencies.
3. Sketchfab CC BY listings support authenticated downloads. Use the official Sketchfab login/Download API. Do not use developer console caches, ripped viewer assets, bypass scripts, or unknown mirrors.
4. Convert permitted FBX to glTF 2.0 binary with Blender. Preserve skinning, UV maps, roughness/normal maps, clip names, and native scale; export with embedded texture images.
5. Verify local SHA-256, GLB integrity, actual mesh triangles, animations, skin mesh, bone transforms, and mobile runtime budget. Adjust the `sha256` value and `installed:true` **in the same reviewed commit** that adds the resulting GLB and passes the tests.
6. Test real desktop + mobile gameplay and cleanup. For a nurse with only a rig and no clips, first build and validate actual idle/walk/attack animations; for the blob, verify the pulsing clip. Never silently substitute the existing goblin or robotic fallback.
7. Finalize optional art only once the server-owned interaction/hitboxes, building entrances, streaming visibility, scene snapshots, game modes, wallets and NFT avatar slots are verified.

## Original in-house horror pass and official artist source gate

The living containment tissue and the playable, smooth-PBR organic crawler in PR #621 are **original BURN City concept geometry**, not substitutions misrepresented as the Sketchfab artist assets. They are designed to maintain environmental tension while the two precise requested GLBs await authenticated official retrieval. The original organic crawler concept uses the existing server's type-5 mechanics and has no new hitbox, damage, spawn type or paid interaction. **The type-8 Warden's existing authentic infected model is intentionally preserved:** visual QA rejected our early low-fidelity nurse-gown placeholder, so that shortcut was removed rather than merging it. Once a licensed and verified living-flesh-blob model is installed, the original crawler concept fallback is automatically bypassed. The nurse becomes active only after the actual licensed artist rig and new animation clips pass quality review.

**Official art metadata confirmed:** KrimzonHaze's mutant nurse is CC BY 4.0, downloadable with an authenticated account, 27,040 triangles, **rigged but zero published animation clips**. Yury Misiyuk's living flesh blob is CC BY 4.0, 9,936 triangles, with one published pulsing clip. Neither has been copied, hotlinked or downloaded using Sketchfab's protected viewer cache.

Run the new manually dispatched GitHub Actions workflow `Manual official Sketchfab Zombies special model source audit` (file `.github/workflows/zombie-special-sketchfab-official-audit.yml`) only when a legitimate **Sketchfab OAuth access token** from a consenting account is available as the repository Actions secret `SKETCHFAB_OAUTH_TOKEN`. The action calls the [documented official Download API](https://sketchfab.com/developers/download-api/downloading-models), checks the author and CC BY license, downloads the expiring glTF archive *without recording its URL*, safely extracts it, converts it offline with Blender, and retains the GLB plus source SHA-256 in a seven-day **review-only artifact**. No secret, signed link, model binary or unreviewed animation is committed, and neither `installed` flag flips automatically. A follow-up artist rig/clip validation and WebGL visual review must pass before a separate reviewed PR can activate either model.

The nurse needs original or independently licensed **idle, locomotion and attack** animations retargeted to its real imported rig, because the Sketchfab source supplies no animation clips. The blob's single pulsation clip must also be inspected for texture and skinning compatibility. Both retain their required artist attribution and change notices.

### Original Zombies isolation
`zombie-special-art.mjs` routes the approved nurse to existing Arena Zombies type 8 and the flesh blob to type 5 for **visual identity only**. They inherit the original game's existing enemy rules and damage, not Homefront logic. The baseline human/hazmat/thin GLBs continue to be used when models are unavailable or fail validation.

### Homefront isolation
`homefront-community-art.mjs` can substitute only the existing visual structure at a road checkpoint or freight depot, instance named objects within the 37-item street pack along preauthored shoulder locations, and add a temporary male-survivor rig onto the present third-person explorer. The original animated walker remains as a safe fallback, and the renderer continues to obey server-owned movement and interaction state. NFT-specific character models remain separate; do not stretch Firekeeper/589 art onto an inaccurate generic human skeleton.

This intake now includes and enables the **street-props GLB and the temporary male-survivor rig**; the military building, abandoned garage, mutant nurse and living flesh blob still require actual source models. No gameplay collision, server movement or Estates code was changed. Real-browser visual QA and release checks remain mandatory before merge.
